# Requirement ทั้งหมดของระบบ Auto Reconcile Bank
(สิ่งที่ผู้ใช้ต้องการให้โปรแกรมทำ — เขียนแบบภาษาพูด)

## A. ความต้องการหลัก (ภาพรวม)

1. อยากได้โปรแกรมที่เอา **ใบแจ้งยอดจากธนาคาร (Bank Statement)** มาเทียบกับ **รายการทางบัญชีใน BC365 (GL)** แล้วจับคู่รายการที่เป็นรายการเดียวกันเข้าด้วยกัน แทนที่จะต้องนั่งไล่เทียบทีละบรรทัดใน Excel เหมือนเดิม
2. อยากให้เป็น **เว็บแอปที่เปิดใช้ผ่านเบราว์เซอร์ในเครือข่ายบริษัท** พนักงานหลายคนใช้พร้อมกันได้ ไม่ต้องติดตั้งโปรแกรมที่เครื่อง
3. อยากให้ทุกอย่างที่จับคู่ไปแล้ว **ถูกบันทึกไว้ตรวจย้อนหลังได้** ว่าใครเป็นคนจับคู่ จับคู่เมื่อไหร่ และถ้าจับผิดต้องยกเลิกได้
4. อยากให้ระบบเป็น **ภาษาไทย** ใช้งานง่าย เจ้าหน้าที่บัญชีที่ไม่เก่งคอมพิวเตอร์ก็ต้องใช้ได้

## B. การเข้าสู่ระบบและสิทธิ์ผู้ใช้

5. อยากให้ **login ด้วย username/password ชุดเดียวกับระบบกลางของบริษัท (TRW Data Center)** ไม่อยากให้ต้องจำรหัสผ่านอีกชุด และไม่อยากให้โปรแกรมนี้เก็บรหัสผ่านเอง
6. อยากมีปุ่มรูปตาให้กดดูรหัสผ่านที่พิมพ์ไปได้ กันพิมพ์ผิด
7. อยากให้ระบบ **เตะออกจากระบบอัตโนมัติเมื่อไม่มีการใช้งาน 30 นาที** เพื่อความปลอดภัย เผื่อลืมปิดหน้าจอแล้วเดินออกจากโต๊ะ
8. อยากให้ **แบ่งสิทธิ์การใช้งานเป็น 3 ระดับ** คือ Admin / User / Dev โดยเมนูที่เข้าไม่ได้ต้องไม่แสดงให้เห็น และต้องกันการพิมพ์ URL เข้าตรงๆ ด้วย
   - คนทั่วไป (User) ให้ใช้ Dashboard, Reconcile, Match History, Suspense, Reports
   - เฉพาะ Admin/Dev เท่านั้นที่เข้าเมนู **Import** และ **Master Data** ได้ (เพราะเป็นเมนูที่แก้ข้อมูลต้นทางได้)

## C. การนำเข้าข้อมูล (Import)

9. อยากอัปโหลด **ไฟล์ Statement จากธนาคารเป็น Excel/CSV** ได้เลย โดยไม่ต้องจัดรูปแบบไฟล์เองก่อน
10. รองรับธนาคารที่บริษัทใช้อยู่ — **กสิกรไทย (KBANK), ไทยพาณิชย์ (SCB), กรุงเทพ (BBL)** ซึ่งแต่ละธนาคารรูปแบบไฟล์ไม่เหมือนกัน ระบบต้องอ่านได้ทั้งหมด
11. อยากให้มี **หน้าดูตัวอย่างข้อมูล (Preview) ก่อนกดนำเข้าจริง** จะได้เห็นก่อนว่าระบบอ่านไฟล์ถูกต้องไหม มีกี่รายการ ยอดรวมเท่าไร
12. อยาก **กันการนำเข้าไฟล์ซ้ำ / รายการซ้ำ** ถ้าเผลออัปโหลดไฟล์เดิมสองรอบต้องไม่ทำให้ยอดเบิ้ล
13. ฝั่ง GL ไม่อยากอัปโหลดไฟล์เอง — อยากให้มี **ปุ่มซิงค์ดึงรายการจาก BC365 มาตรงๆ** กดปุ่มเดียวจบ
14. อยากให้การนำเข้าแต่ละครั้งถูกเก็บเป็น **ชุด (batch)** เพื่อให้ย้อนไปดูได้ว่าไฟล์ไหนนำเข้าเมื่อไหร่ มีกี่รายการ

## D. การจัดการข้อมูลต้นทาง (Master Data)

15. อยากดู **รายการที่นำเข้าไปแล้วทั้งหมด** ได้ ทั้งระดับไฟล์และระดับรายบรรทัด
16. อยาก **แก้ไข / ลบ / เพิ่มรายการด้วยมือ** ได้ กรณีที่ statement มีรายการผิดหรือตกหล่น
17. แต่ต้อง **แก้ได้เฉพาะรายการที่ยังไม่ถูกจับคู่เท่านั้น** — รายการที่ match ไปแล้วห้ามแก้ กันข้อมูลเพี้ยนย้อนหลัง
18. ฝั่ง GL **ห้ามแก้ในโปรแกรมนี้เด็ดขาด** ถ้าผิดต้องไปแก้ที่ BC365 แล้วกดซิงค์ใหม่ เพราะ BC365 เป็นระบบบัญชีตัวจริง
19. ตารางรายการต้องมี **ตัวกรอง (filter) และแบ่งหน้า (pagination)** เพราะข้อมูลเยอะมาก เลื่อนหายาว

## E. การกระทบยอด (Reconcile) — งานหลักที่ใช้ทุกวัน

20. อยากเลือกได้ก่อนว่าจะทำ **ธนาคารไหน และช่วงวันที่ไหน** แล้วค่อยเข้าไปหน้าจับคู่
21. อยากเห็น **ข้อมูล 2 ฝั่งคู่กันบนหน้าจอเดียว** — ซ้ายเป็นธนาคาร ขวาเป็น GL — เลือกติ๊กแล้วกดจับคู่ได้เลย
22. กติกาการจับคู่ที่ต้องการ:
    - **ทิศทางต้องตรงข้ามกัน** — เงินเข้าฝั่งธนาคารต้องคู่กับเดบิตฝั่ง GL และในทางกลับกัน แสดงเป็นป้าย IN / OUT ให้เห็นชัด
    - **ต้องเป็นวันที่เดียวกัน**
    - **ยอดรวม 2 ฝั่งต้องเท่ากันพอดี** ถ้าไม่เท่ากันปุ่ม Match ต้องกดไม่ได้ (ยอมให้ต่างกันได้ไม่เกิน 0.005 บาท จากการปัดเศษ)
23. ต้องจับคู่ได้ **หลายรูปแบบ ไม่ใช่แค่ 1 ต่อ 1** — ทั้ง 1:1, 1:N (ธนาคาร 1 รายการ ต่อ GL หลายรายการ) และ N:1 (ธนาคารหลายรายการ ต่อ GL 1 รายการ)
24. ฝั่ง GL อยากให้ **แยกแท็บตามเลขบัญชี** จะได้ดูทีละบัญชีไม่สับสน
25. อยากให้ GL **ขยายช่วงวันที่ได้มากกว่าฝั่งธนาคาร** เพราะบางรายการลงบัญชีคนละวันกับวันที่เงินเข้าออกจริง
26. อยากมีปุ่ม **“Suggest matches” ให้ระบบหาคู่ให้อัตโนมัติ** — ระบบต้องหาให้ได้ทั้งคู่ที่ยอดตรงกันตรงๆ และคู่ที่ต้องรวมหลายรายการให้ยอดเท่ากัน
27. แต่คู่ที่ระบบแนะนำ **ต้องให้คนดูและกดยืนยันก่อนเสมอ ห้ามบันทึกเอง** — อยากมีหน้า preview ให้ตรวจก่อนกด
28. ถ้าปิดหน้าจอหรือรีเฟรชไปแล้วกลับมา **อยากให้งานที่ค้างอยู่ยังอยู่** (ธนาคาร/ช่วงวันที่ที่เลือกไว้) ไม่ต้องเริ่มใหม่ — จะล้างก็ต่อเมื่อ logout หรือกดเริ่มรอบใหม่เอง

## F. ประวัติการจับคู่และการยกเลิก (Match History / Unmatch)

29. อยากมีหน้า **ประวัติการจับคู่** ดูย้อนหลังได้ว่าจับคู่อะไรไปแล้วบ้าง พร้อมชื่อคนทำและเวลา
30. อยากเห็น **รายการฝั่งธนาคารและฝั่ง GL ของคู่นั้นอยู่ในตารางเดียวกัน** จะได้ดูเทียบง่าย ไม่ต้องเปิดสองที่
31. อยาก **ยกเลิกการจับคู่ (Unmatch) ได้** ถ้าจับผิด แล้วรายการต้องกลับไปเป็นสถานะยังไม่จับคู่เพื่อไปจับใหม่ได้
32. การยกเลิกต้องทำได้ **ทั้งยกเลิกทั้งใบ และยกเลิกเฉพาะกลุ่มย่อยข้างใน** และเลือกยกเลิกหลายกลุ่มพร้อมกันได้
33. ก่อนยกเลิกต้องมี **กล่องยืนยัน** กันกดพลาด
34. รายการที่ยกเลิกไปแล้ว **ต้องยังเก็บประวัติไว้** ไม่ใช่ลบทิ้ง เพื่อให้ตรวจสอบ (audit) ได้ว่าเคยจับคู่แล้วยกเลิกโดยใคร

## G. บัญชีพักโอน (Suspense)

35. รายการที่หาคู่ไม่เจอจริงๆ อยาก **พักไว้ก่อน (Suspense)** ไม่ให้ค้างรกอยู่ในหน้าจับคู่ทุกวัน
36. พักได้ **เฉพาะฝั่ง GL เท่านั้น** — ฝั่ง Bank Statement ห้ามพัก เพราะเป็นเอกสารจากธนาคารที่แก้ไม่ได้
37. อยากมี **หน้ารวมรายการที่พักไว้ทั้งหมด** พร้อมตัวกรอง
38. อยากเห็น **อายุของรายการที่ค้าง (aging)** ว่าค้างมากี่วันแล้ว จะได้รู้ว่าอันไหนต้องรีบตาม
39. อยาก **ดึงรายการกลับไปจับคู่ใหม่ (Unsuspend) ได้** เมื่อหาคู่เจอแล้ว
40. อยาก **เลือกทีละหลายรายการแล้วดึงกลับพร้อมกันทีเดียว** พร้อมกล่องยืนยันก่อนทำ

## H. รายงาน (Reports)

41. อยากได้ **รายงานสรุปการกระทบยอดรายเดือน** แบบเทียบ 2 ฝั่ง ดูได้ว่าเดือนนี้ตรงกันเท่าไร เหลือค้างเท่าไร
42. อยากมี **ตัวกรอง** เลือกธนาคาร/ช่วงเวลาที่ต้องการดูได้
43. อยากมีปุ่ม **Export เป็นไฟล์ Excel** เพื่อเอาไปทำงานต่อ ส่งผู้บริหาร หรือส่งผู้สอบบัญชี
44. อยากให้ตัวเลขในรายงาน **ตรงกับที่เคยทำมือ 100%** ใช้ปิดงบได้จริง

## I. หน้าสรุปภาพรวม (Dashboard)

45. อยากมี **หน้าแรกที่เห็นภาพรวมทันทีที่ login** ว่าเดือนนี้กระทบยอดไปกี่เปอร์เซ็นต์แล้ว
46. อยากเห็นเป็น **การ์ดตัวเลขสรุป (KPI)** เช่น จำนวนรายการทั้งหมด / จับคู่แล้ว / ค้าง / พักไว้
47. อยากเห็นเป็น **กราฟ** ด้วย — สัดส่วนสถานะ, ความเคลื่อนไหวรายวัน, แนวโน้มย้อนหลัง
48. อยากเห็น **รายการที่ค้างนานที่สุด** และ **แยกยอดตามธนาคาร**
49. อยาก **เลือกเดือน / ปรับมุมมองได้** ว่าจะดูภาพรวมหรือดูเจาะเฉพาะธนาคารไหน
50. ตัวเลขทั้งหมดต้องเป็น **ข้อมูลจริงจากฐานข้อมูล** ไม่ใช่ตัวอย่าง

## J. ความต้องการอื่นๆ (Non-functional)

51. อยากให้ระบบ **รันบนเซิร์ฟเวอร์ของบริษัท (Windows Server)** ข้อมูลไม่ออกไปข้างนอก และเปิดค้างไว้ตลอด รีสตาร์ตเครื่องแล้วต้องขึ้นเองอัตโนมัติ
52. ข้อมูลทั้งหมดเก็บใน **ฐานข้อมูล SQL Server ของบริษัท** แยกฐานข้อมูลของระบบนี้ออกมาชัดเจน
53. อยากให้หน้าจอ **ตอบสนองเร็ว** แม้ข้อมูลจะเป็นหลักพันรายการ
54. อยากให้ระบบ **บอกสถานะด้วยสีและป้ายที่เข้าใจง่าย** เป็นมาตรฐานเดียวกันทั้งระบบ
55. อยากได้ **คู่มือการใช้งานภาษาไทย** ที่อธิบายทีละหน้าจอ ทีละปุ่ม พร้อมภาพประกอบ ไว้ให้พนักงานใหม่อ่านเองได้
56. อยากให้ระบบ **ปลอดภัย ไม่มีช่องโหว่** ของ library ที่ใช้
